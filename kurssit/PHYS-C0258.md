## Description

Quantum Labs is a laboratory course during which four different quantum technology related experiments are completed. Officially, the course is set to start in the first period. However, during the last couple of years, the course has had a one-month-radio-silence and has actually started approximately a month later. Therefore, if no information about the course is given during the first weeks, there is no need to panic.

## Contents and workload

The course is completed in groups of four. There are five different experiments, and groups get randomly assigned to four of them.

### Overall workload

{% include stars.html count=4 %}

The workload is based on having to find suitable times for all the group members to join the experiments — which can be quite difficult sometimes — and having to write a report on all four experiments. (one report/group member) The actual workload depends greatly on the experiments assigned to you as some of them require more data analysis than others.

### Weekly contents

There are no weekly lectures, but the experiment topics have been as follows:

| Experiment | Topic |
|------------|-------|
| 1 | Characterization of a Superconducting Transmon Qubit |
| 2 | Temperature-dependent Noise Measurement |
| 3 | Dual Path Interference |
| 4 | Conduction quantization |
| 5 | Superconducting Quantum Interference Device (SQUID) |

## Practicalities

Each report is being graded by the TAs.

Each student gets points from the report that they have written + 1/5 × (sum of points from 3 other reports in the group).

Pass threshold = 4.8 (pass if grade superior or equal to 4.8).

At the end of the course, there is a final presentation in which each group presents one of the experiments they completed.

## Trivia

It can happen that your group has booked a slot for an experiment, but that slot gets later on deleted due to maintenance or cooling of cryostats. In such cases, the TA asks for you to book a new slot.
